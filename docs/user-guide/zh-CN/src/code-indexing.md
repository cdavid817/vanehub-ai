# 索引工作区代码

工作区代码索引让 OnePiece 无需反复扫描所有文件即可定位定义和相关代码。打开**设置 > Agent 配置 > OnePiece**，先配置 OpenAI-compatible embedding 来源，再使用**工作区代码索引**。

## 配置索引

1. 选择**添加工作区**并选择本地目录。
2. 打开该工作区的配置并启用索引。
3. 选择要索引的相对根目录和语言。支持 JavaScript、TypeScript/TSX、Python、Rust、Go、Java、C 和 C++。
4. 每行填写一个额外排除 glob，并设置单文件大小上限。默认上限为 100 KiB。
5. 保存并刷新文件清单，检查文件数和代码块预估。
6. 外部 embedding 开始前，确认准确的工作区、提供商配置、模型、代码块数和预计批量请求数。

代码索引默认按工作区停用。每个工作区分别保存相对根目录、语言、排除规则和文件大小上限。

## 隐私边界

VaneHub 在解析前应用嵌套 `.gitignore` 和用户排除规则。.env、凭证文件、私钥和 PEM 文件等强制敏感模式不能被配置覆盖。符合规则的代码块在 embedding 前会扫描并脱敏，但确认后，脱敏代码仍会发送到所选的外部 embedding 提供商。

确认与工作区索引代次、提供商配置和模型绑定。重建索引、修改索引配置或切换 embedding 配置/模型后必须重新确认。等待确认期间，本地关键词检索仍然可用，并严格限制在当前工作区。

## 保留与删除

停用索引会保留配置和已有索引，之后可继续使用。**重建**只删除该工作区的文件清单、代码块、符号和向量，然后重新扫描。**删除**会永久移除该工作区的配置、索引数据和本地审计记录，不影响其他工作区索引或 Agent 记忆。

关闭工作区不会删除索引。如果根目录已移动或不可访问，状态会显示**根目录不可用**；应注册新路径并重建，不要假设原工作区身份会自动跟随目录。
