# 斜杠命令：在输入框里直接操作界面

## 功能概述

在会话输入框敲 `/`，可以直接切页签、改执行模式、看用量，不必把手从键盘挪到侧栏。

**这些命令由前端执行，不是发给模型的消息**。它们操作的是已有的会话与界面能力——`/mode execute` 改的是会话的执行模式开关，不是请模型「进入执行模式」。

## 可用命令

输入 `/` 会弹出补全候选，输入 `/help` 列出当前会话可用的全部命令。

**打开界面：**

| 命令 | 作用 |
| --- | --- |
| `/todo` | 打开待办看板 |
| `/loops` | 打开循环中心 |
| `/files` | 打开文件页签 |
| `/changes` | 打开变更页签 |
| `/documents` | 打开文档页签 |
| `/report` | 打开报告页签 |
| `/logs` | 打开日志页签 |
| `/traces` | 打开追踪页签 |
| `/shell` | 打开 Shell 页签 |
| `/terminal` | 打开终端页签 |

**切换会话开关：**

| 命令 | 作用 |
| --- | --- |
| `/mode <值>` | 设置执行模式 |
| `/thinking <值>` | 切换思考开关 |
| `/streaming <值>` | 切换流式输出 |
| `/longcontext <值>` | 切换长上下文 |

**查看与导出：**

| 命令 | 作用 |
| --- | --- |
| `/help` | 列出可用命令 |
| `/status` | 显示当前运行时开关 |
| `/usage` | 显示本会话的 Token 用量 |
| `/export` | 导出当前会话 |

`/usage` 会给出总 Token、输入 Token、输出 Token 和回复次数。

## 什么算命令

判定很严格，**全部条件同时满足**才算：

- 去掉首尾空白后是**单行**
- 以**单个** `/` 开头
- `/` 之后紧跟一个**以字母开头**、只含字母、数字和连字符的名称
- 名称之后是空白或输入结束

命令名**大小写不敏感**，名称之后的内容按连续空白切成参数。

两个最容易撞上的反例：

- **`/usr/bin/env` 不是命令**，它会作为普通消息发出去。名称后面紧跟 `/` 不满足「空白或结束」这一条。
- **多行文本不是命令**，哪怕第一行正好是 `/help`。

## 想真的发一个以斜杠开头的句子

用 `//` 开头，系统会**去掉一个 `/` 后作为普通消息发送**。提交 `//help` 发出去的是 `/help` 这段文字，不会执行任何命令。

**这个转义之所以必要，是因为未知命令不会被转发给模型**。没有它，任何以 `/` 真实开头的散文都发不出去。

## 命令在哪些会话里生效

**只有内置原生 Agent 的会话启用斜杠命令**，判定依据是稳定的 agent 标识，不是显示名称——改个显示名不会改变行为。

在未启用的会话里，命令形态的输入**当普通消息发送**。也就是说在一个 CLI Agent 会话里敲 `/mode execute`，模型会收到这行文字，执行模式不变。

另外，**每条命令还有自己的适用条件**。`/help` 列出的是当前会话真正可用的命令，不适用的不会出现在列表里。

## 命令不会到达模型

被命令层接管的输入**不发给模型，输入框被清空**。这个判定在提交时同步完成，所以不会出现「消息已发出又被撤回」的中间状态。

命令本身的执行可以是异步的，结果完成后再呈现。

## 出错时会怎样

| 情况 | 反馈 | 副作用 |
| --- | --- | --- |
| 未知命令 | 「未知命令 /xxx，试试 /help。」 | **不发送任何消息** |
| 参数不合法 | 列出该命令的合法取值 | **无** |
| 执行失败 | 「命令执行失败」 | 通过服务边界上报 |

**未知命令绝不静默转发给模型**。静默转发会让你以为消息送到了，实际上模型收到的是一串你没打算发的命令文本。

参数不合法时同样**不产生任何副作用**——`/mode nonsense` 会报错并列出合法取值，执行模式保持原样。

## 命令输出在哪

**命令输出呈现在聊天消息列表之外**，右上角可以关闭。

它**不作为消息持久化，也不出现在会话导出里**。原因很实际：消息列表每轮发送后都会从后端重新拉取，本地注入的条目活不过一次刷新。放在列表之外，输出才能在无关的重新拉取后依然可见。

## 补全

输入框内容为 `/` 或 `/` 加部分名称时，会按名称前缀过滤出候选。

**光是打字永远不会执行命令**。逐字符键入 `/mode execute` 而不提交，执行模式不会有任何变化。

## 注意事项与限制

- **仅内置原生 Agent 会话生效**，其他会话里命令形态的输入按普通消息处理。
- **命令名保持英文**，切换界面语言只会改变描述、输出和错误提示的语言，命令名本身不翻译——这样跨语言都能输入。
- **命令输出不进导出**，需要留档的内容请用 `/export` 导出会话本身。
- **`/` 后面接路径不会被当成命令**，但如果你要发的句子恰好以 `/` 加字母开头，记得用 `//`。
