# VaneHub AI 用户指南

<a href="../en/index.html">English</a>

本指南面向**使用 VaneHub AI 的开发者**，讲清怎么装、怎么用、出问题怎么查。

刚上手请从[快速开始](quick-start.md)。术语不熟先看[核心概念](core-concepts.md)。想看完整场景走一遍，看[使用案例](use-cases.md)。

## 状态标签

- **已交付** —— 用户可见路径已经实现并经过验证。
- **预览** —— Service 或 mock contract 已存在，但正常产品工作流尚未完成。
- **仅 Web/mock** —— 确定性的浏览器行为，不会产生 native side effect。
- **仅桌面端** —— 依赖 Tauri runtime 与本地操作系统访问能力。
- **规划中** —— 当前尚不可用。

各标签的判读方式见 [Runtime 与功能状态标签](runtime-labels.md)。

## 本指南不讲什么

**内部实现与设计动机不在这里。**想了解架构如何切分、某个机制为什么这样设计、代码在哪，见另一套中文文档《VaneHub AI 中文文档》——它面向开发者与贡献者。

两者分工：

| 想知道 | 去哪 |
| --- | --- |
| 这个按钮点了会怎样 | 本指南 |
| 这个功能为什么这样设计 | 中文文档（架构篇） |
| 出错了怎么办 | 本指南的[故障排查](troubleshooting.md) |
| 代码在哪个文件 | 中文文档（架构篇） |
