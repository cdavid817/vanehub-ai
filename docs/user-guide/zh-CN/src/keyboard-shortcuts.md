# 快捷键

本页只收录已核对当前界面、并有测试覆盖的真实快捷键与交互模型，不是愿望清单。

## 全局

| 快捷键 | 作用 |
| --- | --- |
| **Ctrl/Cmd+K** | 打开命令中心——搜索命令并跳转到某个业务域 |
| **/** | 聚焦当前页面自己的搜索框（前提是你没有正在别的输入框里打字） |
| **Enter** | 发送当前消息（输入框内） |
| **Shift+Enter** | 换行（输入框内） |
| **Escape** | 关闭当前打开的对话框、Sheet 或菜单 |

## 标签条

应用里所有标签条——会话工作区的主标签、运行时面板、任务控制台的分区导航、部分设置页内部的标签组等——共用同一套模型：

| 按键 | 作用 |
| --- | --- |
| **左/右方向键** | 切到上一个/下一个标签 |
| **Home / End** | 跳到第一个/最后一个标签 |
| **上/下方向键** | 极少数纵向标签条也支持（例如个性化页的视图切换） |

## 菜单

行操作菜单、工作区溢出菜单、席位切换器等弹出菜单：

| 按键 | 作用 |
| --- | --- |
| **下方向键 / Enter / 空格**（在触发按钮上） | 打开菜单，焦点落在第一项 |
| **上/下方向键** | 在选项间移动 |
| **Home / End** | 跳到第一项/最后一项 |
| **Enter / 空格** | 激活当前项 |
| **Escape** | 关闭菜单，焦点回到触发按钮 |

## 搜索式选择器

命令中心、设置搜索、快速打开对话框、输入框的 `@` 提及补全，都是焦点留在输入框本身、下方用虚拟选中项来导航的组合控件：

| 按键 | 作用 |
| --- | --- |
| **上/下方向键** | 移动高亮的结果 |
| **Enter** | 选中当前高亮的结果 |
| **Escape** | 不选择，直接关闭 |

## 对话框与 Sheet

所有对话框和滑出式 Sheet 都会把 **Tab** 焦点锁在内部——在最后一个可聚焦控件上按 Tab 会回到第一个——按 **Escape** 关闭，关闭后焦点回到打开它的那个控件。

## 拖拽手势也有键盘路径

拖拽从来不是唯一做法：任务看板卡片移动有对应的"移动到…"菜单，把文件引用拖进输入框也有粘贴路径和上面的 `@` 提及补全可用。这两条路径本身没有专属快捷键——通过菜单或补全列表来达成即可。
