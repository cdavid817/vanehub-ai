# 无障碍说明

以下是对照当前界面与其测试覆盖核实过的真实情况，不是愿景陈述，也不是合规认证。

## 键盘可操作性

应用里的每一种交互模式——标签条、菜单、搜索式选择器、对话框、Sheet——都可以完全用键盘操作，且同一模式在全应用行为一致。完整列表见[快捷键](keyboard-shortcuts.md)。有两种 ARIA 模式应用里确实没有用到，因此也没有为了"看起来完整"而硬造：没有 `role="tree"`/`role="grid"` 内容，也没有 `role="toolbar"` 式的轮转焦点分组（各个 `*-toolbar` 面板里的控件都是彼此独立的 Tab 停靠点，对于混合了搜索框和按钮的工具条来说这本来就是正确形状）。

## 焦点管理

- **关闭对话框或 Sheet 会把焦点还给打开它的控件**，而不是丢回页面顶部——应用里所有对话框和 Sheet 共用同一个焦点陷阱实现。
- **吸顶元素不会挡住已聚焦的内容。** 吸顶表头、输入框、运行时面板、Loop 中心的验收面板都预留了足够的滚动边距，聚焦控件被滚动到可视区域时不会被它们挡住。

## 状态从不只靠颜色区分

状态、优先级、通过/失败、信任、关注、回归等指示器，颜色之外必定配一段文字标签——这是结构性保证（共享的 `Badge`/`StatusBadge` 组件要求必须传 label，不是靠各处调用方自觉遵守的约定），不需要逐屏幕再核实一遍。

## 减弱动效

界面遵循操作系统的 **prefers-reduced-motion** 设置，对开启了该选项的用户跳过非必要动画。

## 自动化扫描覆盖范围——真实但不完整

自动化 axe-core 无障碍扫描目前覆盖 **Agent 评测、任务控制台、任务看板、目标中心**，且在 Futuristic 与 Minimal 两套主题下都跑。**尚未覆盖**会话工作区（本应用自己的默认、访问最频繁的业务域）、项目与工作区、循环中心、定时任务，以及设置的任何一个页面——即便在已覆盖的四个业务域里，也只扫描了每个域的一个已填充状态，并非每一种可达子状态。请把这四个已覆盖业务域理解为"抽查过"，而不是"整个应用已认证"。

## 语言

界面默认跟随宿主系统的 locale，而不是固定从某一种语言启动；随时可以在**设置 → 基础配置**里改，见[用户界面](user-interface.md#基础配置)。
