# Provider icon provenance

The SVG files under `cherry/` were copied from Cherry Studio commit
`03d266e0299d4ca44ce88f5cc6df398922c83147`:

- `packages/ui/icons/providers/light/*.svg`
- `packages/ui/icons/models/light/xiaomimimo.svg`
- `packages/ui/icons/models/light/zai.svg`
- matching files under `providers/dark/` and `models/dark/` where Cherry Studio
  publishes a dark variant; providers without one reuse the light asset

`stepfun -> step`, and `xiaomi -> xiaomimimo`. MiniMax and MiniMax Global share the
