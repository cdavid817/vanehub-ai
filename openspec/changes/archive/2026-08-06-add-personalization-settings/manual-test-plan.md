# 手动测试文档：个性化功能（add-personalization-settings）

对应 `tasks.md` 任务 10.8。覆盖自定义指令、记忆开关、记忆管理、以及本轮代码审查修复的 3 个 bug 的验证。

## 前置条件

1. 在真实 desktop 环境（`npm run tauri dev` 或已打包应用）启动 VaneHub AI。
2. 设置 → **Agent 配置** → **OnePiece** 标签页：确认已有一个可用的 Provider 配置（有 API key、状态为"就绪"）。没有的话先点"新增配置"配好一个（DeepSeek/Anthropic/任意 OpenAI-compatible 均可），点"启用"激活。
   - 这一步是所有后续测试的地基——OnePiece 打不通，后面全测不了。
3. 建议准备一个干净的测试工作区/会话，避免历史记忆干扰判断（或者接受历史记忆存在，在 E/F 节测试前先用"重置全部"清空一次）。

## 记录方式

每条用例执行后在"结果"里填 ✅ 通过 / ❌ 不通过 / ⏭️ 跳过（附原因）。❌ 的用例请把实际现象记下来反馈回来。
