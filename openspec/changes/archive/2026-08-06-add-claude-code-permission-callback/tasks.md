## 4. Hook wrapper binary

**Regression found by the user, not caught by any automated check in this pass:** `npm run tauri:dev` failed outright — `cargo run could not determine which binary to run ... available binaries: vanehub-ai, vanehub-permission-hook`. Tauri's `tauri dev`/`tauri build` both invoke plain `cargo run`/`cargo build` with no `--bin`, which is ambiguous the moment a second `[[bin]]` target exists in the same package. Worth folding into 8.2 or a new check for future changes that add binary targets.

**Unrelated environmental finding, not a code issue:** this machine's shell has `all_proxy=socks5://127.0.0.1:9999` set, which makes `reqwest`-based tests hitting `127.0.0.1` come back with a bogus `502` instead of the real response — cost one confusing failure (`wrong_token_is_rejected_before_evaluation` briefly looked broken) before finding the cause. Recorded in memory (`env-socks5-proxy-breaks-playwright-cli.md`, now broadened beyond just Playwright); any `cargo test`/`npm test` run touching a loopback server on this machine should use `env -u all_proxy -u ALL_PROXY` if results look wrong in a way that doesn't match the code.
