## 3. ApprovalBroker (`src-tauri/src/contexts/permissions/application/`)

- [x] 3.1 Implement the pending-approval queue as the Rust-side source of truth, keyed by a generated request id (carrying `session_id`/`generation_id`/`call_id`/`project_key` on each `ApprovalRequest`). **Implementation refinement**: kept purely in-memory (`Arc<Mutex<HashMap<...>>>`), no `PendingApprovalRepository`/SQLite table — a pending approval only means anything while its generation's process is alive, mirroring how `RuntimeAgentApiAdapter`'s own per-generation pending map already works; nothing meaningful would survive an app restart to recover anyway
- [x] 3.2 Implement resolution (`finalize`): approve/deny + scope choice; `Once` does not persist a grant, `Session`/`Project`/`Global` does — but only when `delivered = true` (see 3.4)
- [x] 3.3 Implement timeout sweep (`sweep_timed_out`): unresolved pending approval past the timeout window is removed and audited with `AuditDecider::Timeout` (best-effort — an audit-write failure still lets the swept request through, since a hung generation would be worse than a missed audit row). **Caller-side wiring is group 6's job, not this one**: `await_approval`'s existing blocking-wait loop needs zero changes to receive a timeout — a periodic sweeper just needs to call this then deliver `ToolApprovalDecision::Denied` through the *existing* `AgentRuntimeApi::resolve_tool_approval(session_id, call_id, ...)` path for each swept request, the exact same channel a human `Deny` already uses
- [x] 3.4 Implement staleness handling: `finalize` takes a `delivered: bool` the caller determines from `AgentRuntimeApi::resolve_tool_approval`'s own return value (design.md D8 refinement) — `false` records `AuditDecider::StaleGeneration` and skips grant creation, `true` records `AuditDecider::Human`
- [x] 3.5 Wire `approval_audit` writes for every resolution path (human decision, stale-generation via 3.4; timeout via 3.3; policy Allow/Deny already covered in `EvaluationService`, group 2)
- [x] 3.6 Unit tests: create/list/get pending, finalize removes and grants correctly per scope, finalize when not delivered records `StaleGeneration` and skips the grant, finalize on an unknown id returns `None`, timeout sweep only removes expired requests
