## REMOVED Requirements

### Requirement: Representative Multi-Agent coding workflow
**Reason**: The requirement mandated that the guide set demonstrate task decomposition, stable primary and fallback Agent selection, prerequisite relationships, a dependency graph, output propagation, cancellation, and final result review. Every one of those behaviours belongs to the retired `multi-agent-coordination` capability, so the requirement would oblige the documentation to describe a workflow the product no longer has.

**Migration**: None. The remaining guide requirements — localized task-oriented guides, truthful feature-state labeling, deterministic screenshots, and safe accessible media — are unchanged and continue to govern the documentation set.
